# Schultz Mission Website

This repository contains the source code for our family missionary website.

The site is built using:

- HTML
- CSS
- JavaScript (if needed)

It is hosted using GitHub Pages.

For changes to the site:

1. Open VS Code → mission-website
2. Make changes
3. Ctrl + S
4. Test locally
5. Terminal:
    git status
    git add .
    git commit -m "Describe changes"
    git push origin main

6. Wait for GitHub Pages to deploy
7. Refresh the live website
